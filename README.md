# SCP Traders website

React + Vite website concept for SCP Traders, based on the current project supplied by the user.

## Run locally

1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.
5. Run `npm run build` to create a production build in `dist/`.

## Product navigation

- Hover over **All Products** on desktop to open the two-level product menu.
- Hover or focus a category to see its listed products and sizes.
- On mobile, open the menu and tap a category to show its products. Use **View all** to filter the full product list.
- **Categories** links directly to the category section; it has no duplicate dropdown.
- Search filters the product catalogue by product name, category, or size.

## Product data and launch checklist

The category/product names and capacities are based on publicly visible catalogue listings from Sri Amman Polymers / Amman Polypet. Some listings show inconsistent capacities across the page, so confirm the exact model and capacity with the supplier before publishing. Product photos are illustrative placeholders and should be replaced with SCP Traders-approved product photos.

This is a front-end demo. Login, cart/enquiry list, order tracking, and chat are not connected to a backend service. The email enquiry link opens the visitor's configured email app without a preset recipient; add SCP Traders' real business email before launch.
